# 言語タスクのデモ

1. プロジェクトのルートで `./run.sh` または `./run_genesis_gui.sh` を実行します。
2. [指示画面](http://127.0.0.1:8000/simple) を開き、Genesis と接続中であることを確認します。
3. 「シーンを初期化」を押し、完了を待ちます。
4. 次の指示を入力して「実行」を押します。

   ```text
   右手がBlue Cubeを取って左手に渡した後に置いて、その左手にあるRED CUBEを掴んで右手がそれを取って右手のところに置く
   ```

5. 解釈された全工程を確認し、Genesis の独立したウィンドウで両腕を観察します。
6. 両方の配置に「確認済み」と計測誤差が表示されるまで待ちます。
7. 「計測結果と実行ログ」を開くと、接触と追従による判定を確認できます。
8. 初期化後、「曖昧な指示」の例でも同じ手順を試せます。

短い指示を分ける場合は、「右手で青いキューブを掴んで」が完了した後に
「それを左手に渡して左側に置く」と送れます。途中で初期化は不要です。

停止は実際のモーター制御に伝わります。停止後は計測された状態から次の指示を解釈し、
物体を最初の位置へ戻す回復はしません。受け手が別のキューブを持っている場合は、先に置く指示が必要です。

定型文だけで操作する場合は `OPENARM_LOCAL_PLANNER=0 ./run.sh` を使います。
モデルを使えない場合やモデル回答が検証を通らなかった場合、実際に用いたフォールバックが表示されます。

再現用の実行コマンドと検証範囲は [README](../README.md)、構成は [ARCHITECTURE](ARCHITECTURE.md) に記載しています。
